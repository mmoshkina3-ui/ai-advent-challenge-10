# День 4. Температура

Модель: `deepseek-flash`.
Рассуждение выключено: в документации DeepSeek параметр `temperature` в thinking-режиме не действует.
Допустимый диапазон temperature: от 0 до 2. Значение 1.2 внутри диапазона.
Каждая пара «задача + temperature» запущена 5 раз.
Ключ в репозиторий не входит.

## Задача с одним ответом

Запрос: Сколько будет 17 умножить на 23? Ответь одной строкой строго в виде: Ответ: <число>

Верный ответ: 391. Формат соблюдён, если весь ответ состоит из одной строки `Ответ: <число>`.

| temperature | Верных | Формат сломан | Одинаковых ответов |
| --- | --- | --- | --- |
| 0 | 5 из 5 | 0 из 5 | уникальных текстов: 1 |
| 0.7 | 5 из 5 | 0 из 5 | уникальных текстов: 1 |
| 1.2 | 5 из 5 | 0 из 5 | уникальных текстов: 1 |

Примеры:

### temperature 0

1. верно, формат ок: `Ответ: 391`
2. верно, формат ок: `Ответ: 391`
3. верно, формат ок: `Ответ: 391`
4. верно, формат ок: `Ответ: 391`
5. верно, формат ок: `Ответ: 391`

### temperature 0.7

1. верно, формат ок: `Ответ: 391`
2. верно, формат ок: `Ответ: 391`
3. верно, формат ок: `Ответ: 391`
4. верно, формат ок: `Ответ: 391`
5. верно, формат ок: `Ответ: 391`

### temperature 1.2

1. верно, формат ок: `Ответ: 391`
2. верно, формат ок: `Ответ: 391`
3. верно, формат ок: `Ответ: 391`
4. верно, формат ок: `Ответ: 391`
5. верно, формат ок: `Ответ: 391`

## Задача на генерацию

Запрос: Придумай ровно 5 коротких названий для мобильного приложения учёта личных финансов. Каждое название с новой строки. Без нумерации, пояснений и пустых строк.

Формат соблюдён, если в ответе ровно 5 непустых строк без нумерации.

| temperature | Формат сломан | Уникальных наборов из 5 |
| --- | --- | --- |
| 0 | 0 из 5 | 3 |
| 0.7 | 0 из 5 | 5 |
| 1.2 | 0 из 5 | 5 |

Примеры:

### temperature 0

1. формат ок: Копилка / ФинГлаз / ДеньгиТут / Баланс / Трата
2. формат ок: Копилка / ФинГид / Бюджет+ / Деньги / Учёт
3. формат ок: Копилка / ФинГид / Бюджет / Деньги / Учёт
4. формат ок: Копилка / ФинГид / Бюджет / Деньги / Учёт
5. формат ок: Копилка / ФинГлаз / ДеньгиТут / Баланс / Трата

## Вывод

На задаче «17 умножить на 23» temperature 0 дала один и тот же текст все 5 раз: `Ответ: 391`. При 0.7 и 1.2 текст тоже не менялся. Неверных ответов 0, сломанный формат 0. Разнообразие здесь не нужно: правильный ответ один, и модель его не теряла.

На названиях temperature 0 не дала один и тот же набор. Из 5 прогонов вышло 3 разных списка. При 0.7 и 1.2 все 5 наборов разные. Формат не сломался ни разу: каждый ответ был из 5 строк. Здесь разнообразие полезно, потому что задача просит новые варианты, а не единственное число.

Какую настройку брать:
- temperature 0 для счёта, проверки и строгого формата. На этой задаче ответ совпал во всех прогонах.
- temperature 0.7, когда нужны разные формулировки, а формат ещё должен держаться. Названия менялись каждый раз, строка `Ответ: 391` не поехала.
- temperature 1.2 для поиска идей. На названиях она дала самый разный список. На простом умножении она не сломала ответ, но и пользы не добавила.
