# День 9. Сжатие истории

Агент хранит полный журнал у себя. В модель уходят только последние 6 сообщений. Каждые 10 более старых сообщений заменяются памяткой. Памятка лежит отдельно в поле `summary` и подставляется в системный текст вместо этих сообщений.

Модель `deepseek-flash`, рассуждение выключено. Стоимость по обычному тарифу: кэш $0.003, промах $0.15, выход $0.60 за 1 миллион токенов.

## Детали, заданные заранее

15 фактов, каждый отдельным сообщением. Вместе с короткими ответами «принято» это 30 сообщений. Потом 15 вопросов, по одному на факт.

| Деталь | Что сказали |
| --- | --- |
| Имя | заказчик Максим |
| Срок | 15 декабря 2026 |
| Бюджет | 120000 рублей |
| Ограничение | нельзя использовать облако |
| Решение | пишем на Python |
| Город | Казань |
| Команда | 4 человека |
| Встречи | по вторникам в 10:00 |
| База | нельзя менять базу данных |
| Отчёт | формат PDF |
| Порядок | сначала поиск, потом оплата |
| Почта | max@example.com |
| Версия | версия 3 |
| Пароль | не короче 12 символов |
| Язык | интерфейс только на русском |

## Что агент ответил

Оба режима ответили по всем 15 деталям. Первая автоматическая проверка засчитала 12 и 13: она не узнала короткие верные ответы «Нельзя», «Поиск» и «Версию 3». По тексту ответов это те же факты.

Со сжатием к началу вопросов 20 из 30 сообщений уже были внутри памятки. К концу вопросов в памятке было 50 сообщений. Все 15 вопросов задавались, когда исходная реплика с фактом уже не входила в сырой хвост. Памятка при этом содержала все 15 пунктов, от имени Максим до «интерфейс только на русском языке».

На этом диалоге сжатие ничего не потеряло.

## Токены

| | Без сжатия | Со сжатием |
| --- | ---: | ---: |
| Вызовы чата | 30 | 30 |
| Вызовы памятки | 0 | 5 |
| Токены запросов чата | 13394 | 8941 |
| Токены запросов памятки | 0 | 1546 |
| Токены запросов всего | 13394 | 10487 |
| Токены ответов | 94 | 774 |
| Последний запрос | 764 | 352 |
| Стоимость | $0.000937 | $0.001586 |

Последний запрос со сжатием вдвое меньше: 352 против 764. Запросы чата тоже меньше: 8941 против 13394. Вместе с пятью вызовами памятки все запросы всё ещё меньше: 10487 против 13394.

Деньги на этом коротком диалоге выросли: $0.001586 против $0.000937. Памятка сама является ответом модели, 657 токенов выхода, а выход дороже входа. Пока реплики короткие, сжатие уменьшает следующий запрос, но ещё не окупает отдельный вызов памятки. Чем длиннее журнал, тем сильнее растёт запрос без сжатия, а со сжатием он остаётся размером с памятку плюс 6 последних сообщений.

Запуск:

python compare_context.py
