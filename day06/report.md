# День 6. Первый агент

Агент в `agent.py` держит историю сообщений и крутит цикл: запрос в DeepSeek, вызов инструмента, возврат результата, снова запрос. Цикл кончается, когда модель отвечает текстом без `tool_calls`. Модель `deepseek-flash`, рассуждение выключено. Ключ в репозиторий не входит.

Инструменты, это обычные функции в коде:

| Инструмент | Что делает |
| --- | --- |
| `get_current_time` | Локальные дата и время |
| `calculate` | Выражение из чисел и знаков + - * / |
| `convert_usd_to_rub` | Доллары в рубли по курсу 90 |

| Проверка | Ход агента | Ответ |
| --- | --- | --- |
| Без инструментов: что такое агент | Шаг 1, сразу текст | Агент сам выбирает действия и инструменты |
| Один инструмент: сколько сейчас времени | `get_current_time` -> 2026-11-09 15:34:48 | Сейчас 15:34:48 |
| Один инструмент без подсказки: 15 долларов в рублях | `convert_usd_to_rub(15)` -> 1350 RUB | 1350 рублей |
| Два инструмента подряд: 15 долларов в рубли и умножить на 2 | сначала `convert_usd_to_rub(15)` -> 1350, затем `calculate(1350 * 2)` -> 2700 | 2700 рублей |

Запуск:

```powershell
cd day06
python agent.py Сколько будет 15 долларов в рублях?
```
