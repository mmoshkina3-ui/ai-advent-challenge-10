# День 1. Первый запрос к LLM через API

Скрипт `ask_llm.py` отправляет вопрос на OpenRouter, читает ответ и печатает его в консоль. Модель `openrouter/free`. Ключ лежит в `.env` и в репозиторий не входит.

| Шаг | Что сделали | Результат |
| --- | --- | --- |
| Запрос | `POST https://openrouter.ai/api/v1/chat/completions` | HTTP 200 |
| Вопрос | Привет! Ответь одним предложением: что такое LLM? | отправлен |
| Ответ | LLM (Large Language Model) — это тип искусственного интеллекта, который обрабатывает и генерирует текст, основанный на анализе огромных объемов данных. | напечатан в консоли |

Задание закрыто: запрос ушёл через API, ответ получен и показан в консоли.
