# День 7. Сохранение контекста

Агент тот же, что в дне 6: класс `Agent`, цикл до ответа без инструментов, три функции. Дополнительно каждый шаг сразу пишется в `day07/history.json`. Файл в git не попадает.

В файле лежит весь диалог: `system`, `user`, `assistant` с `tool_calls` и `tool` с результатом. При новом запуске `python agent.py` читает этот файл и продолжает разговор. Флаг `--new` начинает с пустой истории.

Проверка тремя отдельными процессами, модель `deepseek-flash`, рассуждение выключено.

| Запуск | В памяти до вопроса | Что спросили | Что сделал агент | Ответ |
| --- | --- | --- | --- | --- |
| 1, `--new` | 0 | Меня зовут Максим. Запомни это имя. | Шаг 1, сразу текст | Запомнил, Максим |
| 2, новый процесс | 2 | Переведи 15 долларов в рубли. | `convert_usd_to_rub(15)` -> `15.0 USD = 1350 RUB по курсу 90` | Максим, 1350 рублей |
| 3, ещё один процесс | 6 | Как меня зовут и сколько рублей получилось при прошлом переводе? Ответь по памяти. | Шаг 1, инструмент не вызывал | Максим, 1350 рублей |

Третий процесс не вызывал перевод заново. Имя и сумму он взял из сохранённых сообщений и результата инструмента.

Запуск из папки day07:

python agent.py --new Меня зовут Максим. Запомни это имя.

python agent.py Переведи 15 долларов в рубли.

python agent.py Как меня зовут и сколько рублей получилось при прошлом переводе?
